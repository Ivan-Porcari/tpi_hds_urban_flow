# Urban Flow

## Sprint actual: Sprint 1

## Objetivo
Aplicar conocimientos de versionado de código, organización, limpieza de datos y uso de pandas sobre un dataset de multas por exceso de velocidad.

## Introducción y contexto
La localidad de Vaalserberg (Bélgica), ubicada en zona fronteriza con Países Bajos y Alemania, cuenta con radares urbanos para detectar infracciones de velocidad. Los registros históricos provienen de sistemas heredados con errores de formato y datos faltantes. 
El objetivo del Sprint 1 es analizar y depurar esos datos para incorporarlos al nuevo sistema sin inconsistencias.
